# 📖 CLI Interactive Manager: Localized User Guide

This guide provides step-by-step instructions for running and operating the `cli_manager.py` control terminal interface in multiple regional languages.

---

## 🇮🇳 1. Hindi User Guide (हिंदी उपयोगकर्ता गाइड)

यह गाइड प्रोजेक्ट बायोवोल्ट के भूमिगत क्लस्टर नोड को नियंत्रित करने वाले इंटरैक्टिव कमांड-लाइन इंटरफ़ेस (`cli_manager.py`) को संचालित करने की पूरी प्रक्रिया समझाती है।

### 🚀 कंसोल कैसे शुरू करें
अपने टर्मिनल में निम्नलिखित कमांड चलाएँ:
```bash
python simulator/cli_manager.py
```

### ⚙️ मुख्य विकल्प और उनका उपयोग:
1. **Poll Live Telemetry Sensor Node Streams (लाइव टेलीमेट्री सेंसर स्ट्रीम):**
   - यह विकल्प जमीन के नीचे 10-30 मीटर गहरे कैसॉन नोड्स से रीयल-टाइम डेटा (एनोड वोल्टेज, तापमान, आंतरिक प्रतिरोध) प्राप्त करता है। जानकारी तुरंत `biovolt_operations.log` फ़ाइल में सहेज ली जाती है।
2. **Run Systems Diagnostics (PEM मैट्रिक्स स्कैन):**
   - सॉफ़्टवेयर प्रोटॉन एक्सचेंज मेम्ब्रेन (PEM) की कार्यात्मक स्थिति की जांच करता है। यह किसी भी विपरित धातु संदूषण (जैसे लेड आयनों का रिसाव) या झिल्ली के सूखने की समस्या को ट्रैक करता है।
3. **Execute Emergency Remote Override Command (आपातकालीन रिमोट ओवरराइड):**
   - **FORCE_ISOLATE:** किसी भी संरचनात्मक विफलता की स्थिति में बायो-एनोड को तुरंत मुख्य लेड-कार्बन बैटरी बैंक से अलग कर देता है।
   - **RESUME_HARVEST:** अलार्म साफ़ होने के बाद पीएमआईसी (PMIC) चार्जिंग गेट को फिर से सक्रिय करता है।
4. **Access Local Job Pipeline Tracking Ledger (एप्लिकेशन ट्रैकिंग लेज़र):**
   - यह आपके लोकल `job_applications.csv` डेटाबेस को खोलकर आपकी सक्रिय नौकरी अनुप्रयोगों की वर्तमान स्थिति प्रदर्शित करता है।

## 🇮🇳 2. Odia User Guide (ଓଡ଼ିଆ ବ୍ୟବହାରକାରୀ ଗାଇଡ୍)

ଏହି ଗାଇଡ୍ ପ୍ରକଳ୍ପ ବାୟୋଭୋଲ୍ଟର ଭୂତଳ କ୍ଲଷ୍ଟର ନୋଡ୍କୁ ନିୟନ୍ତ୍ରଣ କରୁଥିବା ଇଣ୍ଟରଆକ୍ଟିଭ୍ କମାଣ୍ଡ-ଲାଇନ୍ ଇଣ୍ଟରଫେସ୍ (`cli_manager.py`) କୁ ପରିଚାଳନା କରିବାର ସମ୍ପୂର୍ଣ୍ଣ ପ୍ରକ୍ରିୟା ବୁଝାଇଥାଏ।

### 🚀 କନସୋଲ୍ କିପରି ଆରମ୍ଭ କରିବେ
ଆପଣଙ୍କର ଟର୍ମିନାଲ୍ରେ ନିମ୍ନଲିଖିତ କମାଣ୍ଡ ଚଲାନ୍ତୁ:
```bash
python simulator/cli_manager.py
```

### ⚙️ ମୁଖ୍ୟ ବିକଳ୍ପ ଏବଂ ଏହାର ବ୍ୟବହାର:
୧. **Poll Live Telemetry Sensor Node Streams (ଲାଇଭ୍ ଟେଲିମେଟ୍ରି ସେନ୍ସର ଷ୍ଟ୍ରିମ୍):**
   - ଏହି ବିକଳ୍ପ ମାଟି ତଳେ ଥିବା କାଇସନ ନୋଡ୍ରୁ ରୀଅଲ-ଟାଇମ ଡାଟା (ଆନୋଡ୍ ଭୋଲ୍ଟେଜ୍, ତାପମାତ୍ରା, ଆଭ୍ୟନ୍ତରୀଣ ପ୍ରତିରୋଧ) ସଂଗ୍ରହ କରେ ଏବଂ ସଙ୍ଗେ ସଙ୍ଗେ `biovolt_operations.log` ଫାଇଲ୍ରେ ସାଇତି ରଖେ।
୨. **Run Systems Diagnostics (PEM ମ୍ୟାଟ୍ରିକ୍ସ ସ୍କାନ୍):**
   - ସଫ୍ଟୱେର୍ ପ୍ରୋଟନ୍ ଏକ୍ସଚେଞ୍ଜ ମେମ୍ବ୍ରେନ୍ (PEM) ର ସ୍ଥିତି ଯାଞ୍ଚ କରେ। ଏହା କୌଣସି ବିପଦଜନକ ଧାତବ ପ୍ରଦୂଷଣ (ଯେପରିକି ସୀସା ଆୟନର ଲିକ୍) କିମ୍ବା ମେମ୍ବ୍ରେନ୍ ଶୁଖିଯିବା ସମସ୍ୟାକୁ ଟ୍ରାକ୍ କରିଥାଏ।
୩. **Execute Emergency Remote Override Command (ଜରୁରୀକାଳୀନ ରିମୋଟ୍ ଓଭରରାଇଡ୍):**
   - **FORCE_ISOLATE:** କୌଣସି ଯାନ୍ତ୍ରିକ ତ୍ରୁଟି ଦେଖାଦେଲେ ବାୟୋ-ଆନୋଡକୁ ସଙ୍ଗେ ସଙ୍ଗେ ମୁଖ୍ୟ ଲେଡ-କାର୍ବନ ବ୍ୟାଟେରୀ ବ୍ୟାଙ୍କରୁ ଅଲଗା କରିଦିଏ।
   - **RESUME_HARVEST:** ଆଲାର୍ମ ସଫା ହେବା ପରେ PMIC ଚାର୍ଜିଂ ଗେଟ୍କୁ ପୁନର୍ବାର ସକ୍ରିୟ କରିଥାଏ।
୪. **Access Local Job Pipeline Tracking Ledger (ପାଇପଲାଇନ୍ ଟ୍ରାକିଂ ଲେଜର):**
   - ଏହା ଆପଣଙ୍କର ଲୋକାଲ୍ `job_applications.csv` ଡାଟାବେସ୍ ଖୋଲି ଆପଣଙ୍କର ସକ୍ରିୟ ଚାକିରି ଆବେଦନଗୁଡ଼ିକର ବର୍ତ୍ତମାନର ସ୍ଥିତି ପ୍ରଦର୍ଶନ କରେ।
